# Трекер тренировок

**Автор / псевдоним:** veta surik

## Что делает программа
Консольный трекер тренировок. Можно добавлять упражнения (название, вес, повторения), смотреть список и считать общий объём тренировки (вес × повторения).

## Как запустить
Нужен Python 3. Команда запуска:

```
python main.py
```

## Проверка 1 
- Вход: пункт 1, название «ягодичный мост», вес 120, повторения 8, затем пункты 2 и 3
- Ожидание: упражнение добавлено, в списке одна запись, общий объём 960
- Результат: всё работает как ожидалось, объём 960

## Проверка 2 
- Вход: пункт 1, в вес и повторения введены буквы
- Ожидание: сообщение об ошибке, программа не падает и возвращается в меню
- Результат: показано «Ошибка: вес и повторения должны быть целыми числами», меню работает дальше
